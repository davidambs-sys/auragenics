MEDRIXX — Webflow handoff
=========================

You cannot import this Grok app into Webflow as a project.
Webflow Designer is a visual CMS; this rebuild is a React app.
Use this kit to recreate it in your existing medrixx.com Webflow site.

  Submit → Webflow form notifications / email

HOW TO BUILD IN WEBFLOW (fastest path)
  1. Open the existing medrixx.com Webflow project.
  2. Upload every file in /images to Assets.
  3. Add the two Google fonts and the swatches above.
  4. Keep your current CMS/form if it already emails you; restyle it to match.
  5. Rebuild page by page while the Grok preview is open as the visual source.
  6. Do not paste the React code into an Embed — it will not run.

IF YOU WANT THIS VERSION LIVE WITHOUT WEBFLOW
  Publish the Grok app instead. It is already the full site.
  Then point medrixx.com at that host, or keep Webflow and restyle there.

Copy, disclaimers, and page text match the Grok preview exactly.
